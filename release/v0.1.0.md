针对 [alibaba/open-code-review](https://github.com/alibaba/open-code-review) 的 DeepSeek Harness 社区插件，使用 Apache-2.0 许可证并保留上游归属。

- 直接复用官方 OCR v1.14.4，完整透传 CLI 子命令与参数。
- 原样分发 native / delegate 两个技能和 GitHub PR 工作流。
- 提供 dsh 工具、取消与超时处理、完整输出保存，以及交互式 `dsh-ocr` 终端入口。

已通过 21 项测试及 Windows / Linux、Node.js 22.19 / 24 的 CI。安装包已在真实 DSH 0.2.2-rc.5 profile 中加载并调用官方 CLI；原生模型审查需要另外配置 OCR provider。

安装到你的 dsh profile：

```sh
dsh plugin --profile code-review add --ignore-scripts https://github.com/listky/dsh-ali-open-code-review/releases/download/v0.1.0/dsh-ali-open-code-review-0.1.0.tgz
```

官方平台依赖已包含二进制，`--ignore-scripts` 可跳过上游的安装下载脚本。使用方法及凭据配置见 [README](https://github.com/listky/dsh-ali-open-code-review#readme)。
